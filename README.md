!notes c4:4 would play a C in the 4th Octave (Middle C) for the duration 4 (a 1/4 note)

So to play a tune, you could type something like this:

!notes e4:4 d4:4 c4:4 d4:4 e4:8 r:8 e4:8 r:8 e4:2 d:8 r:8 d:8 r:8 d4:2 e4:8 r:8 g4:8 r:8 g4:2

for the first half of mary had a little lamb. 



The First half of the colon tells the chat what note to play! You can use all chromatic notes, c, c#, d, eb, e, f, f#, g, ab, a, bb, b     and an r represents a "rest" or a silence where there should be no notes!
The number before the colon is the octave (how high or low, from ~1-5)

The second half of the colon is how long each note lasts! The higher the number, the smaller the note (like actual musical notation): 
1 is a note that lasts a whole measure, 2 is half of the measure, 4 is a quarter, 8 is an eighth of the measure, and 16 is a 16th of the measure.
